# flight sql execution flow

## helpers

### pre_precess_statement_query_req

> IN: sql, MetadataMap

1. call `cnosdb::flight_sql::auth_middleware::CallHeaderAuthenticator::authenticate(MetadataMap)`
2. call build_query_state_machine(sql), get QueryStateMachine
3. call build_logical_plan(QueryStateMachine), get Plan

> OUT: Plan, QueryStateMachine

### pre_precess_statement_query_req_and_save

> IN: sql, MetadataMap

1. call pre_precess_statement_query_req(sql, MetadataMap), get (Plan, QueryStateMachine)
2. result_cache.insert(uuid, (Plan, QueryStateMachine))

> OUT: uuid, Schema

### precess_flight_info_req

> IN: sql, FlightDescriptor

1. call pre_precess_statement_query_req_and_save(sql, FlightDescriptor.MetadataMap), get uuid, Schema
2. call construct_flight_info, get FlightInfo

> OUT: FlightInfo

### construct_flight_info

> IN: uuid, Schema, FlightDescriptor

call `arrow_flight::gen::FlightInfo::new()`

> OUT: FlightInfo

### construct_context

> IN: User, MetadataMap

call `spi::service::protocol::ContextBuilder::new().build()`

> OUT: Context

### build_query_state_machine

> IN: sql, Context

call `spi::server::dbms::DatabaseManagerSystem::build_query_state_machine()`

> OUT: QueryStateMachine

### build_logical_plan

> IN: QueryStateMachine

call `spi::server::dbms::DatabaseManagerSystem::build_logical_plan()`

> OUT: Plan

### execute_logical_plan

> IN: Plan, QueryStateMachine

call `spi::server::dbms::DatabaseManagerSystem::execute_logical_plan()`

> OUT: QueryHandle

### get_plan_and_qsm

> IN: uuid

result_cache.get(uuid)

> OUT: Plan, QueryStateMachine

### execute_and_fetch_result_set

> IN: uuid

1. call get_plan_and_qsm(uuid), get Plan, QueryStateMachine
2. call execute_logical_plan(plan, QueryStateMachine), get QueryHandle
3. call `arrow_flight::utils::batches_to_flight_data()`, get Iterator_FlightData

> OUT: FlightService::DoGetStream
